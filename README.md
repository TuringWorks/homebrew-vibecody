# homebrew-vibecody

Homebrew tap for [VibeCody](https://turingworks.github.io/vibecody).

```
brew tap turingworks/vibecody
brew install vibecli          # CLI + daemon
brew install --cask vibecoder    # desktop code editor
brew install --cask vibedesk     # desktop task shell
brew install --cask vibeaichat   # desktop AI assistant
```

This tap is generated by `scripts/packaging/render_homebrew_tap.py` in the
[vibecody](https://github.com/TuringWorks/vibecody) repo's release pipeline,
one release at a time — do not hand-edit `Formula/` or `Casks/` here, changes
will be overwritten on the next release.
